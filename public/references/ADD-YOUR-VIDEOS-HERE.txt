ADD YOUR 4 REFERENCE VIDEOS TO THIS FOLDER
==========================================

You are in the right place. Put the files here, next to this note.

RENAME THEM TO EXACTLY THESE NAMES
----------------------------------
The app matches these names literally, so a typo means the clip stays hidden.

  1.  orbital-drift.mp4
  2.  pulse-grid.mp4
  3.  liquid-bloom.mp4
  4.  light-sweep.mp4

The MP4 is the only file you need. Cards autoplay muted once they scroll
into view, so the clip previews itself.

DO NOT ADD GIFs
---------------
A GIF seems like the obvious way to show motion and is the one thing that
cannot work here: a poster image is always STATIC, so the browser draws
frame one of the GIF and stops. You pay 20-35MB to show what a 40KB JPG
would show.

It is backwards on size too. GIF has no interframe compression, which is why
the same clip is 20MB as a GIF and 2MB as an MP4. The file you already have
is both the smaller one and the only one that moves.

If you made GIFs, delete them — especially before committing, since git
keeps every version of a binary forever and 90MB of them will make the repo
slow to clone for good.

An optional <name>.jpg still is supported but not needed.

WHICH CLIP GOES WHERE
---------------------
The names describe the MOTION, not the colour, because that is what the
model actually copies from a reference. Match your Envato clips to these:

  orbital-drift  slow drifting, floating, soft collisions, long easing
                 -> for products that should feel weightless and premium

  pulse-grid     hard rhythmic pulses on a regular beat
                 -> for concepts cut to music, where actions land on beats

  liquid-bloom   fluid expansion outward from the centre, organic
                 -> for pours, splashes, anything spreading or bursting

  light-sweep    a highlight raking across a dark field
                 -> borrowed for lighting behaviour, not movement

If your four clips do not match these four moods, rename the slots instead:
edit src/lib/referenceClips.ts and change the id, name, brief and file for
each. The picker follows that file.

KEEP THEM SMALL
---------------
  - 4 to 6 seconds. These models read the camera move, not the content.
    Longer buys nothing.
  - Aim for 2-3MB. The 4MB cap shown on the upload button does NOT apply to
    these — that limit exists because a browser upload passes through a
    serverless request, and these never do. But they are served to every
    visitor who scrolls to them, so size still matters.
    On a Mac: QuickTime > File > Export As > 720p re-encodes a heavy one.
  - 720p is plenty. It is a motion reference, not footage.
  - No text, no faces, no recognisable products — anything in the clip can
    leak into your ad.

AFTER YOU ADD THEM
------------------
  npm run dev     picks them up immediately, no restart
  npm run build   needed before `npm start`, because the page prerenders

Then open the Ad Lab, scroll to step 6 References, and they appear under
"Starter motion clips".

You can delete this file once the videos are in.
